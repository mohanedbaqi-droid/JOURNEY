# JOURNEY Android 2.4.54 (Build 86)

تحديث أندرويد متوافق مع مشروع JOURNEY وESP عبر BLE محلياً، مع تجربة مسار الإنترنت MQTT المشفّر.

## ما الذي أضيف في هذه النسخة؟
- **الديمو مدمج بنفس التطبيق** من الإعدادات، وليس APK منفصلاً. لا يتصل بـESP أو MQTT أثناء المحاكاة.
- أزرار التجربة **تحت صورة الجورني بالشاشة الرئيسية**: فتح وقفل، تشغيل تجريبي بعد مصادقة الجهاز، الأبواب الأربعة، الصندوق، البنيد، الواطي والبروجكتر والإشارتين والفلشر.
- صورة السيارة تتفاعل مع حالات الأبواب والإضاءة الموجودة. البنيد يظهر تحذير بدلاً من صورة فتح غير متوفرة.
- **ويدجتان أندرويد** (صغير وكبير) لعرض الحالة. بالديمو الفتح والقفل يعملان مباشرة من الويدجت؛ بالوضع الحقيقي يفتح التطبيق حتى يؤكد الأمر. تشغيل المحرك دائماً يحتاج مصادقة الجهاز.
- **حالة السيارة على شاشة القفل** من خلال إشعار اختياري في الإعدادات، وليس Live Activity الخاص بـiOS. يتحكم Android بشكل الإشعار وخصوصيته.
- **TLS MQTT عبر الإنترنت**: نفس مواضيع iOS، وهي `journey/<deviceID>/state` و `journey/<deviceID>/cmd`. يجب إدخال بيانات الخادم وDevice ID الصحيح.
- BLE ما زال يعمل، وأولوية الاتصال (BLE / Wi-Fi / CELLULAR) تُحفظ محلياً ويُرسل ترتيبها إلى ESP إذا كان متصلاً.
- حفظ كلمة مرور MQTT مشفّرة باستخدام Android Keystore على Android 6+؛ وعلى Android 5 لا تُحفظ كلمة المرور حتى إعادة التشغيل.
- فحص OBD، قراءة ومسح DTC بتأكيد، مراقبة حرارة ESP وإعداد عتبة التحذير، Wi-Fi، إعدادات 4G وOTA والإصدار لا تزال موجودة.
- **القفل والتشغيل لا يكتسبان لون نجاح لمجرد الضغط**؛ حالة الجهاز تعتمد على قراءات ESP التي وصلت فعلاً.

## حدود يجب معرفتها
- تشغيل MQTT الحقيقي يحتاج خادم فعلي وجهاز ESP مضبوطاً على نفس Device ID. لم يتم إثباته بسيارة حقيقية من اختبار البناء.
- ويدجت Android يتحدث عند وصول البيانات للتطبيق؛ Android قد يؤخر تحديث الويدجت إذا كان التطبيق موقوفاً. إشعار شاشة القفل ليس خدمة تتبع مستمرة بالخلفية.
- لا يوجد في هذا الإصدار مزامنة مع Apple Watch، فهي إضافة watchOS للآيفون فقط.
- إضافات iOS مثل Apple Keychain وActivityKit ليست جزءاً من نظام Android؛ استخدمنا البدائل الملائمة.
- **الحد الأدنى Android 5.0 / API 21** بسبب Jetpack Compose؛ API 18 غير مدعوم في هذا البناء.
- النسخة الموقعة APK مخصصة للتجربة. التحكم بالسيارة الحقيقية وOBD يحتاجان اختباراً على الجهاز.
