# JOURNEY Android 2.4.32 (64)
نسخة تثبيت APK موقعة للفحص، متوافقة مع ESP v12.76.

- صورة الجورني الأمامية والجانبية، أبواب مستقلة حسب البتات المثبتة، نهاري مع RPM صالح، بروجكتر مع السكن والواطي وإشارات مستقلة.
- تم حذف سطر حالات الأبواب تحت الصورة حسب الطلب.
- عربي / إنكليزي، واجهة داكنة أو فاتحة واختيار صورة محفوظ.
- التحكم محلي عبر BLE إلى ESP. إعدادات Wi-Fi و4G وOTA تُرسل إلى ESP. MQTT من هاتف الأندرويد وويدجيت وخدمة القرب في الخلفية ليست ضمن هذا الإصدار.
- تسجيل هاتف/طلب موافقة الآيفون المالك دون مسح الأجهزة الموجودة.
- الأخضر يعتمد على خرج ESP وليس ضغط الزر؛ القراءة القديمة تصبح غير متاحة.
- OBD scan/select، قراءة ومسح DTC بتأكيد، وحفظ ترتيب أولوية ESP. اجعل BLE أولاً للفحص المحلي إذا كان ESP متصلاً بالسيرفر.
- Android 5.0 / API21 فأحدث. minSdk18 القديم غير متوافق فعلياً مع Compose.
- البناء: Java17 + Gradle8.9، الأمر: gradle testDebugUnitTest assembleDebug
- تشغيل APK على السيارة يبقى فحصاً عملياً بعد البناء. الخلفي جهة السائق غير مثبت، لا توجد قراءة وهمية له.

- تحديث الواجهة: بطاقات سوداء وسماوية، تحكم أكبر، مربعات بيانات مستقلة، شريط ثابت مع الرئيسية بارزة. إصدار ESP يُعرض من الحقل firmwareVersion/fw إذا وصل، وإلا غير متصل أو غير مرسل؛ لا رقم ثابت.
